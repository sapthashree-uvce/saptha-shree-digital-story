# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my academic background, technical skills, projects, achievements, certifications, and interests. Designed with a minimal, creative aesthetic using a black, white, and orange colour palette.

### Features

- **About Me:** Introduction, education and personal interests.
- **Technical Skills:** Organized display of programming languages, tools and technologies.
- **Projects:** Showcase of projects with descriptions, technology stacks and GitHub links.
- **Achievements & Certifications:** Highlights of accomplishments, workshops and certificates.
- **Contact:** Links to professional profiles and contact information.
- **Integrated Admin Dashboard:** Secure admin access to add, view, update and delete portfolio content without modifying source code.

### Tech Stack

- React.js
- JavaScript
- HTML5 & CSS3
- Node.js & Express.js
- Supabase (Database, Authentication and Storage)

### Design

Modern editorial-style interface featuring bold typography, asymmetrical layouts, orange accents, smooth animations and responsive design.

### Objective

To create a professional digital identity that reflects my technical knowledge, creativity, continuous learning and passion for building practical solutions.
